# Проект "Моя музыка"

Небольшой стартовый репозиторий с приветственным лендингом и базовым интерактивом.

## Что уже реализовано

- Адаптивный приветственный лендинг.
- Приветствие в зависимости от времени суток.
- Карточки треков с добавлением в быстрый плейлист.
- Сохранение плейлиста, темы и любимого жанра в `localStorage`.
- Переключение светлой и тёмной темы.

## Технологии

- HTML
- CSS
- JavaScript (ES Modules)
- Vite

## Запуск

```bash
npm install
npm run dev
```

Открой адрес из терминала (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
npm run preview
```
# Проект: сайт Натальи Камаловой

Небольшой промо-лендинг для автора персональных песен с каталогом треков, фильтрацией, FAQ и формой заявки.

## Что реализовано

- приветственный лендинг с блоками услуг и призывами к действию;
- каталог песен с фильтрами по категориям;
- поиск по песням (название, описание, категория);
- форма заявки с автосохранением черновика в `localStorage`;
- FAQ-аккордеон, отзывы, контакты, мобильное меню;
- анимации появления блоков и кнопка возврата наверх.

## Структура проекта

- `index.html` — основная страница;
- `style.css` — стили интерфейса;
- `script.js` — клиентская логика и рендер контента.

## Быстрый старт

1. Склонируйте репозиторий:
   - `git clone <url-репозитория>`
2. Откройте папку проекта.
3. Запустите `index.html` в браузере.

## Локальный запуск через VS Code / Cursor Live Server

Если используете расширение Live Server:

1. Откройте проект в Cursor.
2. Запустите `Open with Live Server` для файла `index.html`.
